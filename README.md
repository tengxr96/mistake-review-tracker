# Mistake Review Tracker

A CS3354 individual project that helps students record mistakes and identify topics to review.

The idea comes from my own experience: I do not currently save incorrect answers, which makes it difficult to identify weak topics during exam preparation.

Students will import question screenshots, organize records by course and topic, and record error explanations. Each record will have one status: Not Understood, Partially Understood, or Mastered. Students can update and filter these statuses after review.

The initial version uses manual classification. OCR and AI-generated answers are outside its scope.

The initial version will be a Java Swing desktop application with local storage. Students will keep records on their own computers. Accounts and cloud synchronization are outside this version. GUI development and data persistence require further learning.

Current stage: P1 proposal and requirements planning. Implementation has not started.
